# 料金報告書 作成（CSV → PDF）

Busking の運行一覧 CSV（`daily-*.csv`）を読み込み、代理店ごとの「ハイヤーご利用 ご料金明細書」を表示し、ブラウザの印刷機能で PDF として保存するツールです。

**ブラウザ内だけで処理し、ファイルは外部に送信しません。**

## 使い方

1. ページに Busking の運行一覧 CSV（Shift_JIS）をドラッグ&ドロップ
2. 「確認して PDF 化」で絞り込み
   - **発行日**（既定は当日）
   - **出力する代理店**（複数まとめて／1社だけ）
   - **ステータス**（キャンセルなどを除外）
   - **出力する案件**（予約を1行ずつ選択。チェックした案件だけプレビューに表示）
3. 「印刷 / PDF 保存」→ 印刷ダイアログで「PDF に保存」「用紙=A4・向き=横」

## 取り込む列

`予約ID / 状況 / 運行日 / 代理店 / 団体名 / 配車時刻 / 配車場所 / 到着地 / 請求金額`
（金額は税込の「請求金額」、ゲスト名は「団体名」を使用）

## 技術

- 単一の `index.html`（依存は CDN の PapaParse のみ）
- 文字コードは Shift_JIS / UTF-8 自動判定
- GitHub Pages で公開
